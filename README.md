# Trade Ninja

## Description
Simple app built with expo (React Native). The app provides users with a fake cash balance of $100,000 where users can purchase and but indivudal stocks and ETFs. The goal is to grow your cash balance by selecting securities you feel will increase in value.

## Architecture
- Expo (React Native)
- react-navigation
- firebase (real time database)
- firebase (auth)
- react context (state management)
- finnhub.io (real time stock dat api)
